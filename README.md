## The Project
  
A web application inspired by classic 90s video rental stores, recreating the visual and interactive experience of a digital Blockbuster. The project utilizes the TMDB API (The Movie Database) to provide a dynamic catalog of movies, series, and animations, including a personalized Top 5 ranking system.
## Demo
Access the application: https://felipewkx.github.io/blockbuster-hub/

## About the Project
The goal of this project is to recreate the nostalgic experience of video rental stores using modern web technologies and integration with external APIs. The application allows users to explore content from the TMDB database in an organized manner, featuring dedicated pages for different entertainment categories and user personalization features.

## Features

* Unified search within the TMDB catalog
* Navigation by categories
* Dedicated page for movies
* Dedicated page for series
* Dedicated page for cartoons and animations
* Personalized Top 5 ranking system
* Local saving of favorite lists
* Language toggle between English and Portuguese (PT-BR)
* Preference persistence via LocalStorage
* Interface inspired by the retro look of 90s rental stores


## Project Objectives

* Visually recreate the experience of classic rental stores
* Consume and manipulate data from external APIs
* Demonstrate frontend integration with local persistence
* Develop a dynamic application using modern JavaScript
* Create a themed and responsive interface

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6+)
* Fetch API
* LocalStorage
* TMDB API


## Application Structure
The application was organized into multiple pages and independent modules, allowing for simple navigation between available categories. State management is handled on the frontend, including:

* Language control
* Ranking updates
* Local data persistence
* Dynamic interface manipulation


## Key Highlights

* Themed interface inspired by 90s rental stores
* Real-time integration with an external API
* Customized personal ranking system
* Bilingual support
* Local persistence of user preferences
* Modular and scalable structure

## O Projeto

Aplicação web inspirada nas clássicas locadoras dos anos 90, recriando a experiência visual e interativa de uma Blockbuster digital. O projeto utiliza a API do TMDB - The Movie Database para disponibilizar um catálogo dinâmico de filmes, séries e animações, incluindo um sistema personalizado de ranking Top 5.
## Demonstração
Acesse a aplicação: https://felipewkx.github.io/blockbuster-hub/

## Sobre o Projeto
O objetivo deste projeto é recriar a experiência nostálgica das locadoras de vídeo utilizando tecnologias web modernas e integração com APIs externas. A aplicação permite explorar conteúdos da base de dados do TMDB de forma organizada, com páginas dedicadas para diferentes categorias de entretenimento e funcionalidades de personalização para o usuário.

## Funcionalidades

* Busca unificada no catálogo do TMDB
* Navegação por categorias
* Página dedicada para filmes
* Página dedicada para séries
* Página dedicada para desenhos e animações
* Sistema personalizado de ranking Top 5
* Salvamento local das listas favoritas
* Alternância de idioma entre inglês e português (PT-BR)
* Persistência de preferências via LocalStorage
* Interface inspirada no visual retrô das locadoras dos anos 90

## Objetivos do Projeto

* Recriar visualmente a experiência das locadoras clássicas
* Consumir e manipular dados de APIs externas
* Demonstrar integração frontend com persistência local
* Desenvolver uma aplicação dinâmica utilizando JavaScript moderno
* Criar uma interface temática e responsiva


## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript (ES6+)
* Fetch API
* LocalStorage

## Estrutura da Aplicação
A aplicação foi organizada em múltiplas páginas e módulos independentes, permitindo uma navegação simples entre as categorias disponíveis. O gerenciamento de estado é realizado no frontend, incluindo:

* Controle de idioma
* Atualização dos rankings
* Persistência de dados locais
* Manipulação dinâmica da interface


## Diferenciais
